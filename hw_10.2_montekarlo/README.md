# Домашнє завдання: Метод Монте-Карло для обчислення інтеграла

## Мета

Метою завдання було реалізувати алгоритм обчислення визначеного інтеграла функції f(x) = x^2 на проміжку \[0, 2] за допомогою методу Монте-Карло та порівняти отриманий результат із аналітичним розрахунком та результатом, отриманим функцією `quad` з бібліотеки SciPy.

## Методика

1. Метод Монте-Карло:

   * Генеруємо N = 100000 випадкових точок x у межах інтегрування \[0, 2].
   * Обчислюємо значення функції f(x) у цих точках.
   * Знаходимо середнє значення функції та множимо його на довжину інтервалу:
     I ≈ (b - a) \* середнє значення f(x\_i)

2. Аналітичне обчислення:

   * Відомо, що інтеграл від x^2 дорівнює x^3 / 3, отже:
     інтеграл від 0 до 2 = (2^3)/3 - (0^3)/3 = 8/3 ≈ 2.6667

3. Перевірка через SciPy:

   * Використано функцію `quad(f, a, b)`, яка обчислює інтеграл чисельно та повертає похибку обчислення.

## Результати

| Метод                        | Результат | Пояснення                                       |
| ---------------------------- | --------- | ----------------------------------------------- |
| Метод Монте-Карло (N=100000) | \~2.667   | Стохастичний метод, близько до точного значення |
| Аналітичний                  | 2.6667    | Точне значення інтеграла                        |
| SciPy `quad`                 | 2.6667    | Чисельний розрахунок з похибкою \~10^-14        |

## Візуалізація

Нижче наведено графік функції f(x)=x^2 на проміжку \[0,2] та область інтегрування (сіра зона). Для наочності показано частину випадкових точок, які використовуються в методі Монте-Карло.

```python
import numpy as np
import matplotlib.pyplot as plt

# Функція
f = lambda x: x**2

# Межі інтегрування
a, b = 0, 2

# Графік функції
x = np.linspace(-0.5, 2.5, 400)
y = f(x)
fig, ax = plt.subplots()
ax.plot(x, y, 'r', linewidth=2)

# Область під кривою
ix = np.linspace(a, b)
iy = f(ix)
ax.fill_between(ix, iy, color='gray', alpha=0.3)

# Випадкові точки для візуалізації
sample_x = np.random.uniform(a, b, 500)
sample_y = np.random.uniform(0, max(y), 500)
ax.scatter(sample_x, sample_y, s=5, color='blue', alpha=0.4)

ax.axvline(x=a, color='gray', linestyle='--')
ax.axvline(x=b, color='gray', linestyle='--')
ax.set_title('Інтеграл f(x) = x^2 від 0 до 2')
ax.set_xlabel('x')
ax.set_ylabel('f(x)')
plt.grid()
plt.show()
```
